# Plan 064-01: Version Handshake

**Goal:** Worker sends `X-State-Plugin-Version` header; daemon validates against compat range; refuse attach on incompatible versions.
**Requirements:** WRK-13

### Tasks

#### 064.1 — Version compat module
**Acceptance:** `state_core.version` exports `check_version_compat()` and version constants
**Estimated effort:** Small
**Dependencies:** None

<read_first>
- src/state_core/__init__.py
</read_first>

<action>
Create `src/state_core/version.py`:
- `PLUGIN_VERSION: str = "0.1.0"`
- `COMPAT_MAJOR_MINOR: str = "0.1"` — daemon/worker must share this prefix
- `check_version_compat(version_header: str | None) -> tuple[bool, str]`:
  - Returns (True, "") if version starts with COMPAT_MAJOR_MINOR
  - Returns (False, "missing X-State-Plugin-Version header") if None/empty
  - Returns (False, "incompatible version: {v}") otherwise
- `HEADER_NAME: str = "x-state-plugin-version"`
</action>

<acceptance_criteria>
- `grep -q "check_version_compat" src/state_core/version.py`
- `grep -q "PLUGIN_VERSION" src/state_core/version.py`
- `python3 -c "from state_core.version import check_version_compat; r, m = check_version_compat('0.1.0'); assert r; r, m = check_version_compat('0.2.0'); assert not r"` passes
</acceptance_criteria>
