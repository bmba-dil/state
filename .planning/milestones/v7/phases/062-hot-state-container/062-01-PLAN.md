# Plan 062-01: Hot State Container

**Goal:** In-memory pydantic container tracking active Slice/Step/drill, synced from daemon SSE events.

**Requirements:** WRK-11

### Tasks

#### 062.1 — HotState model + apply_event
**Acceptance:** `HotState` model with `active_slice_id`, `active_step_id`, `current_mode`, `in_progress_drill` fields; `apply_event()` updates fields from SSE event payloads
**Estimated effort:** Medium
**Dependencies:** 061

<read_first>
- src/state_core/schema.py (event type constants)
- src/state_worker/bridge.py (SSE callback)
</read_first>

<action>
Create `src/state_worker/hot_state.py`:
- `HotState(BaseModel)`: `active_slice_id: str | None`, `active_step_id: str | None`, `current_mode: str | None`, `in_progress_drill: str | None`
- `apply_event(self, event: dict[str, object]) -> None`: mutates state based on event_type:
  - `slice.planned` → set active_slice_id from event data
  - `slice.shipped` → clear active_slice_id
  - `step.discussed`/`step.planned`/`step.executed` → set active_step_id
  - `step.blocked` → keep step, record block
  - `mode.activated` → set current_mode
  - `drill.prepared` → set in_progress_drill
  - `drill.submitted` → clear in_progress_drill
- Use `from __future__ import annotations`, `pydantic.BaseModel`, `structlog`
</action>

<acceptance_criteria>
- `grep -q "class HotState" src/state_worker/hot_state.py`
- `grep -q "def apply_event" src/state_worker/hot_state.py`
- `python3 -c "from state_worker.hot_state import HotState; h = HotState(); assert h.active_slice_id is None; h.apply_event({'event_type': 'slice.planned', 'data': {'slice_id': 's1'}}); assert h.active_slice_id == 's1'"` 
</acceptance_criteria>
