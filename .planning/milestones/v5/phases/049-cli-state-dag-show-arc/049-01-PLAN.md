**Part A — `render_dag()` function (core engine):**

```python
def render_dag(
    nodes: list[Node],
    edges: list[Edge],
    *,
    filter_kind: str | None = None,
    ascii_only: bool = False,
) -> str:
    """Render a DAG as colored box-drawing art.
    
    Returns a string suitable for terminal output. Uses Rich markup for
    status colors. Unicode box-drawing by default; ASCII fallback via
    ascii_only=True.
    
    Algorithm:
    1. Validate edges — all source/target IDs must exist in nodes list.
       Raise ValueError if any reference is missing (matching frontier/topo_sort pattern).
    2. If filter_kind is set, filter nodes to that kind only; filter edges
       to include only edges where both endpoints are in filtered nodes.
    3. Run topo_sort(filtered_nodes, filtered_edges) to get ordered nodes.
    4. Compute depth for each node: root nodes (no incoming edges) = depth 0,
       others = max(pred_depth) + 1.
    5. Group nodes by depth into rows (list[list[Node]]).
    6. For each row, render each node as a bordered box using Unicode box-drawing
       (or ASCII `+-|` if ascii_only=True):
       
       Unicode:  ┌──────────────────────┐
                 │ <id>  [<status>]     │
                 └──────────┬───────────┘
       
       ASCII:    +----------------------+
                 | <id>  [<status>]     |
                 +----------+-----------+
       
    7. Apply Rich style tags around each box based on node.status per D-02:
       - idle → [dim]<box>[/dim]
       - pending → [yellow]<box>[/yellow]
       - in_progress → [bold cyan]<box>[/bold cyan]
       - done → [green]<box>[/green]
       - blocked → [red]<box>[/red]
       - failed → [bold red]<box>[/bold red]
    8. Between rows, draw connecting lines for edges that span rows.
       Use '│' (vertical) and '├─►' / '└─►' (junction + arrow) characters.
       For ASCII: '|' and '+->' / '+->'.
    9. Return the assembled string.
```

Edge cases to handle:
- Empty nodes list → return empty string ""
- Single node, no edges → render just that node's box
- Nodes at same depth with no edges between them → side-by-side boxes in the same row
- Multiple predecessors to same target → merge lines at the target's column
- Nodes with long IDs → truncate or wrap (use max 60 char width per box)

15. `test_render_dag_never_crashes` — The critical property test:

```python
@given(
    nodes=st.lists(
        st.builds(
            Node,
            id=st.text(min_size=1, max_size=40),
            kind=st.sampled_from(["arc", "phase", "slice", "step"]),
            status=st.sampled_from(["idle", "pending", "in_progress", "done", "blocked", "failed"]),
        ),
        min_size=0,
        max_size=20,
        unique_by=lambda n: n.id,
    ),
)
@settings(max_examples=200)
def test_render_dag_never_crashes(nodes: list[Node]) -> None:
    """Any valid graph (nodes + edges referencing existing nodes) renders without crash."""
    # Generate edges that only reference existing node IDs
    if len(nodes) < 2:
        edges = []
    else:
        from random import Random
        rng = Random(42)  # deterministic seed
        edges = []
        ids = [n.id for n in nodes]
        for _ in range(min(len(nodes) * 2, 30)):
            src = rng.choice(ids)
            tgt = rng.choice(ids)
            if src != tgt:
                edges.append(Edge(
                    source_node=src,
                    target_node=tgt,
                    kind=rng.choice(["blocks", "soft", "data"]),
                ))
    
    # This must never raise
    result = render_dag(nodes, edges)
    assert isinstance(result, str)
```

Use `@settings(max_examples=200, deadline=None)` to avoid timing issues. The key assertion: the function completes and returns a string — no exceptions allowed.

**Important:** Do NOT use `@given` with deferred strategies that depend on `nodes`. Generate edges within the test body using the node IDs (as shown above) since Hypothesis strategies cannot cross-reference generated values easily in this pattern. Use a fixed random seed for reproducibility.
