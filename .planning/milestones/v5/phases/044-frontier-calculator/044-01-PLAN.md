<objective>
Implement `frontier(nodes, edges) -> list[Node]` — the unblocked-set calculator that returns all nodes whose `blocks` and `data` predecessors are `done`. `soft` edges are advisory and do not block. Nodes with status `done` or `failed` are excluded from the frontier.

Purpose: Provide the core "what's ready to run right now" computation that the DAG scheduler (Phase 045 dispatcher) calls on every tick. This is the scheduler's heartbeat — it answers the question "given the current DAG state, which nodes can I dispatch concurrently?"
Output: `frontier()` function in `src/state_core/scheduler.py`, `TestFrontier` test class in `tests/test_scheduler.py`, package export in `__init__.py`.

    ```python
    def frontier(nodes: list[Node], edges: list[Edge]) -> list[Node]:
        """Return unblocked nodes whose blocks/data predecessors are all DONE.

        - Nodes with status 'done' or 'failed' are excluded.
        - Only 'blocks' and 'data' edges block; 'soft' edges do NOT block.
        - A node is unblocked iff ALL its blocks/data predecessors have status 'done'.

        Args:
            nodes: All nodes in the DAG.
            edges: Directed dependency edges (source_node -> target_node).

        Returns:
            Nodes that are unblocked and not done/failed.

        Raises:
            ValueError: If an edge references a source_node not in the nodes list.
        """
        node_map = {n.id: n for n in nodes}

        result: list[Node] = []
        for node in nodes:
            # Exclude done and failed nodes — they're already resolved
            if node.status in ("done", "failed"):
                continue

            # Find all edges targeting this node that are blocking
            blocking_predecessors = [
                edge for edge in edges
                if edge.target_node == node.id
                and edge.kind in ("blocks", "data")
            ]

            # Validate edge endpoints (matching topo_sort pattern)
            for edge in blocking_predecessors:
                if edge.source_node not in node_map:
                    raise ValueError(
                        f"Edge source '{edge.source_node}' not found in node list"
                    )

            # Check all blocking predecessors are done
            all_done = all(
                node_map[edge.source_node].status == "done"
                for edge in blocking_predecessors
            )

            if all_done:
                result.append(node)

        return result
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| list[Edge] → frontier() | Edge list crosses into frontier computation — source_node/target_node references may be invalid |
| list[Node] → frontier() | Node list provides id→status mapping for predecessor checks |
| frontier() → return value | Node references returned to caller — caller must not mutate returned list to inject nodes into DAG |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-044-01 | Tampering | Input list mutation during iteration | accept | frontier() iterates over caller-provided list[nodes] and list[edges]. List mutation during iteration is a Python runtime footgun but frontier operates on copies of node references (not mutating them). Call site is the DAGScheduler which owns the authoritative lists. Accept risk; pydantic models are already frozen. |
| T-044-02 | Spoofing | Edge referencing non-existent source_node | mitigate | Raise `ValueError` when edge.source_node not found in node_map — consistent with topo_sort's validation pattern. Prevents silent frontier miscalculation from dangling edge references. |
| T-044-03 | Denial of Service | Large DAG (many nodes/edges) | accept | frontier() is O(N × E) — linear scan of all edges per node. DAG sizes are bounded by project scale (arcs × phases × slices × steps). Future optimizations (Phase 048 priority inversion) can precompute predecessor indices. Accept for v5 — bounded input. |
| T-044-04 | Information Disclosure | frontier() return value | accept | Returns Node references with string IDs and status enums only. No secrets, credentials, or PII. Frontier is an internal computation consumed by the dispatcher — not exposed to external systems. |
| T-044-05 | Elevation of Privilege | N/A | accept | Pure computation — no auth checks, no external service calls, no file system access. |
| T-044-06 | Repudiation | N/A | accept | frontier() is a stateless pure function. Event-sourced audit trail is handled by the event-store write path (v1 event engine), not by this function. |
</threat_model>
