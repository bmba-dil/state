### Tasks

#### 033.1 Implement OpencodeHTTPWorktreeService

<action>
Create `src/state_core/opencode_worktree.py`:

1. Class `OpencodeHTTPWorktreeService` implementing the `WorktreeService` Protocol
2. Constructor takes `client: httpx.AsyncClient` and `opencode_url: str`
3. `create(name, branch)` → `POST {url}/worktree` with JSON `{"name": name, "branch": branch}` → parse response into `WorktreeInfo`
4. `list()` → `GET {url}/worktree` → parse response list into `list[WorktreeInfo]`
5. `remove(name)` → `DELETE {url}/worktree/{name}` → no-op if 404
6. `reset(name)` → `POST {url}/worktree/{name}/reset` → no-op if 404
7. Handle HTTP errors gracefully (non-200 → log warning, return empty list/raise)
8. Use `structlog` for logging
</action>
