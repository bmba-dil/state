### Tasks

#### 034.1 Implement Pygit2WorktreeService

<action>
Create `src/state_core/pygit2_worktree.py`:

1. Class `Pygit2WorktreeService` implementing WorktreeService Protocol
2. Constructor takes `repo_path: str | Path` (path to git repository root)
3. `create(name, branch)`:
   - Open pygit2.Repository(repo_path)
   - Create branch from HEAD: `repo.create_branch(branch_name, repo.head.target)`
   - Determine worktree dir path: `repo_path / ".." / "state-worktrees" / name`
   - Call `repo.add_worktree(name, worktree_dir)`
   - Return WorktreeInfo with path, name, branch
4. `list()`:
   - Open repo, call `repo.list_worktrees()`
   - For each, `repo.lookup_worktree(name)` to get Worktree
   - Return WorktreeInfo list with locked/prunable populated
5. `remove(name)`:
   - `repo.lookup_worktree(name).prune()`; no-op if not found
6. `reset(name)`:
   - Look up worktree, open its repository, hard reset to branch HEAD
</action>
