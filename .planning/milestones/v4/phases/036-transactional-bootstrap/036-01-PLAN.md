<objective>
Implement transactional worktree bootstrap in `src/state_core/worktree_bootstrap.py`. Atomic three-step process: create branch → create worktree → link `.state/` directory. Compensation rollback on any step failure per WRK-03.
</objective>

### Tasks

#### 036.1 Implement WorktreeBootstrapper

<action>
Create `src/state_core/worktree_bootstrap.py`:

1. `WorktreeBootstrapper` class:
   - `__init__(self, service: WorktreeService, parent_repo_path: Path)`
   - `async bootstrap(arc_id, phase_id, slice_id) -> WorktreeInfo`
   
2. Three-step transaction:
   a. Deterministic branch name from worktree_naming.format_branch
   b. Create worktree via service.create(name, branch)
   c. Link .state/ — copy or symlink `.state/` directory from parent repo into worktree

3. Compensation on failure:
   - Step 3 fails → remove worktree via service.remove(name)
   - Step 2 fails → nothing to undo (step 1 is just a name)
</action>

<acceptance_criteria>
- File at src/state_core/worktree_bootstrap.py
- bootstrap creates worktree via WorktreeService
- .state/ directory is copied into worktree
- Rollback on failure
</acceptance_criteria>
