### Task 2: Implement Observation model (GREEN)

<implementation>
Create `src/state_teach/observations.py` following the Phase 002 discriminated union pattern.

**Sub-models (each with `ConfigDict(extra="forbid", frozen=True)`):**

| Kind | Fields | Description |
|------|--------|-------------|
| `skill_gap` | `skill: str`, `evidence: str`, `confidence: float = 1.0` | Missing prerequisite or skill observed |
| `learning_style` | `style: str`, `evidence: str`, `confidence: float = 1.0` | Preferred learning modality (visual/auditory/kinesthetic) |
| `progress` | `milestone: str`, `concept_id: str`, `mastery_level: float` | Mastery milestone reached |
| `error_pattern` | `pattern: str`, `frequency: int = 1`, `context: str` | Recurring error pattern observed |
| `engagement` | `level: str`, `evidence: str`, `duration_minutes: int \| None = None` | Attention/engagement observation |

**Common base:** `Observation(BaseModel)` with no `kind` Literal — serves as a protocol anchor only. Sub-models each set `kind: Literal["..."] = "..."` as their own discriminator.

**Discriminated union:**
```python
AnyObservation = Annotated[
    SkillGapObservation | LearningStyleObservation | ProgressObservation | ErrorPatternObservation | EngagementObservation,
    Field(discriminator="kind"),
]
```

Use `from __future__ import annotations` at top of file. Import `Annotated`, `Literal`, `Field`, `BaseModel`, `ConfigDict` from pydantic.
</implementation>

<verification>
```bash
python3 -m pytest tests/test_observations.py -v
```
All tests MUST pass.
</verification>
