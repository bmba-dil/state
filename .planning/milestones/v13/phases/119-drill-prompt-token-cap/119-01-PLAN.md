# Phase 119 Plan 01: Token-cap helper for drill prompts

**Objective:** A token-counting helper in `state_teach` that caps drill prompts at ≤3000 tokens (MCP-T-06), with a Hypothesis property test verifying correctness across edge cases.

**Context:**
- @119-CONTEXT.md — AI-discretion implementation; discuss skipped
- @../REQUIREMENTS.md — MCP-T-06: "Drill prompts capped at ≤3000 tokens to prevent bloat"
- Phase 115 provides the `state_teach` package scaffold
- Phase 116 key-decision: "Tool descriptions use plain word-count heuristic ... not literal token counting" — Phase 119 needs a proper token estimator for drill prompts
- The CLAUDE.md REJECTED list includes `tiktoken` — cannot install/use it
- Project uses character-based approximation (`len(text) // 4`) which is the OpenAI-standard rule of thumb (1 token ≈ 4 characters for English text)
- `from __future__ import annotations` on all new `.py` files per established project pattern

## Tasks

### Task 1 — Token-counting helper module (`src/state_teach/tokens.py`)
- **type:** auto
- **tdd:** true

**Behavior:**
- `TOKEN_CAP: int = 3000` — module-level constant
- `count_tokens(text: str) -> int` — returns estimated token count using character-based approximation (`len(text) // 4`, minimum 0)
- Handles edge cases: empty string → 0, whitespace-only → correct count, long prompts
- Pure function: deterministic, no side effects

**Implementation:**
- Google-style docstrings
- `structlog` logger at module level (established pattern)
- Type hints complete

**Verification:**
- `python3 -c "from state_teach.tokens import count_tokens, TOKEN_CAP; assert TOKEN_CAP == 3000"`
- Basic sanity: empty string → 0, "hello" → 1, 12000 chars → 3000

### Task 2 — Hypothesis property test (`tests/test_state_teach_tokens.py`)
- **type:** auto
- **tdd:** true

**Behavior:**
- Hypothesis property test using `from hypothesis import given, strategies as st`
- Properties to verify:
  - **Non-negativity:** `count_tokens(text) >= 0` for all `text` from `st.text()`
  - **Empty string:** `count_tokens("") == 0`
  - **Monotonic-ish:** For any two strings `a, b`, `count_tokens(a + b) >= max(count_tokens(a), count_tokens(b))`
  - **Cap bound:** Any prompt truncated to 3000 tokens never exceeds 3000 tokens
- Unit tests for explicit edge cases: empty string, whitespace, very long string (≥12k chars), exact boundary
- Import lint check: `state_teach` imports must not touch `state_build`

**Verification:**
- `python3 -m pytest tests/test_state_teach_tokens.py -v` — all tests pass
- At least 3 Hypothesis properties execute (not just unit tests with fixed inputs)
- `python3 -m ruff check tests/test_state_teach_tokens.py src/state_teach/tokens.py` — clean
