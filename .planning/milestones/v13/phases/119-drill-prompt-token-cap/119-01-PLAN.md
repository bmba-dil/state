Function 1 — `count_tokens(text: str) -> int`:
- Encode `text` with `_ENCODING.encode(text)`, return `len(tokens)`.
- No logging, no side effects — pure function.
- Empty string returns 0 (implicit from len of empty list).

Function 2 — `enforce_token_cap(prompt: str, max_tokens: int = 3000) -> str`:
- Encode prompt.
- If `len(tokens) <= max_tokens`: return prompt unchanged.
- If over cap: decode only the first `max_tokens` tokens (`_ENCODING.decode(tokens[:max_tokens])`) and return that.
- This truncation is token-aware — cuts at token boundaries, not character boundaries.
- No logging, no warnings, no exceptions — truncation is silent (drill tools should compose prompts under cap; truncation is a safety net).
