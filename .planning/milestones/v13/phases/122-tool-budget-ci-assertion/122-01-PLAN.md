# Phase 122 Plan 01 — Tool-budget CI assertion for state-teach

**Objective:** Wire the existing `state dev tool-budget` CLI infrastructure into a functional entry point, add CI integration, and verify all 14 state-teach tool descriptions are within the ≤80-token budget.

**Context:**
- Phase 108 (v12) already created the `src/state_cli/dev.py` tool-budget command with shared `_SERVER_MODULES` map supporting both `state-build` and `state-teach`
- The command works when called directly from Python but lacks a proper CLI entry point (no `__main__.py`, no `console_scripts` in pyproject.toml)
- Phase 116 registered 14 skeleton tools in `src/state_teach/mcp.py` — all are within budget (114 tokens total against 1200 budget)

## Tasks

### Task 1: Create `src/state_cli/__main__.py` CLI entry point

**Type:** auto

Create the `__main__.py` module so `python -m state_cli dev tool-budget --server state-teach` works from the command line.

<action>
Create `src/state_cli/__main__.py`:
```python
"""CLI entry point for `python -m state_cli`."""
from state_cli.main import app

app()
```
</action>

<verification>
- `test -f src/state_cli/__main__.py` exits 0
- `.venv/bin/python -m state_cli dev tool-budget --server state-teach` prints table and exits 0
- `.venv/bin/python -m state_cli dev --help` lists tool-budget
</verification>

### Task 2: Add `[project.scripts]` console entry point

**Type:** auto

Add a `state` command entry point in pyproject.toml so users can invoke `state dev tool-budget --server state-teach` directly.

<action>
Add to `pyproject.toml` under `[project]`:
```toml
[project.scripts]
state = "state_cli.main:app"
```

Then reinstall the package with the entry point.
</action>

<verification>
- `grep '\[project.scripts\]' pyproject.toml` returns 1 match
- `.venv/bin/state dev tool-budget --server state-teach` prints table and exits 0
</verification>

### Task 3: Create CI assertion script

**Type:** auto

Create a standalone CI script that can be invoked in CI pipelines to verify tool budgets.

<action>
Create `scripts/ci/check-teach-tool-budget.sh`:
```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/../.."
.venv/bin/python -m state_cli dev tool-budget --server state-teach
```
Make it executable.
</action>

<verification>
- `test -f scripts/ci/check-teach-tool-budget.sh` exits 0
- `test -x scripts/ci/check-teach-tool-budget.sh` exits 0
- `bash scripts/ci/check-teach-tool-budget.sh` exits 0
</verification>
