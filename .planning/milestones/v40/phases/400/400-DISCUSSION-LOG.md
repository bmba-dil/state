## Area 2: Cross-tier dependency rules

### Q: Can dependencies cross tier boundaries?
**All options:** Same-parent only (Recommended) | Cross-parent allowed | Same-parent stages, cross-stage slices
**Selected:** Same-parent only. Stages only depend on stages in same arc. Slices only depend on slices in same stage. Keeps dependency graphs bounded and auditable.

### Q: Do Steps within a Slice run serially or in parallel?
**All options:** Serial Steps (Recommended) | Parallel Steps within Slice
**Selected:** Steps run within one agent session, not scheduler-dispatched. The agent organizes work, delegates to subagents, synthesizes, moves to next steps, finalizes, and initiates verification and summary.

### Q: How are dependency edges expressed in artifacts?
**All options:** Frontmatter ID array (Recommended) | Markdown body text | Separate registry file
**Selected:** Frontmatter ID array with edge types: `depends_on: [{id: "slice-10", edge: "blocks"}, {id: "slice-11", edge: "soft"}]`.

**User chose to move to next area after these three questions.**

## Area 3: Blocked & abandon semantics

### Q: When a Slice is abandoned, what happens to dependents?
**All options:** Block dependents + surface (Recommended) | Cascade abandon | Auto assume-satisfied
**Selected:** Block dependents and surface to user. No auto-cascade. User noted need for deferment strategy in frontmatter.

### Q: How should slice/stage deferral work?
**All options:** Deferred status + reason (Recommended) | Backlog re-plan | Placeholder replacement
**Selected:** Deferred status + reason in frontmatter. Dependents treat deferred slices as soft-done.

### Q: Does a blocked Slice time out?
**All options:** No timeout, manual resolution (Recommended) | Escalation warning after timeout
**Selected:** No timeout. Blocked persists indefinitely until deps resolve or user defers blocker. User may shelve project for undetermined time.

### Q: Can Slices be inserted with decimal numbering?
**All options:** Single decimal capped (Recommended) | No decimal, depends_on for ordering
**Selected:** Single decimal level (slice-12.1, slice-12.354), NO cap on decimal number. Must flex for unexpected problems.
