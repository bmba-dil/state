  - No artificial cap — the design scales with project size

  **SECTION 6: Concurrent Access Rules (DSK-06):**

  **Directory Creation Ownership:**
  | Directory | Created By | When |
  |-----------|-----------|------|
  | `.state/build/arcs/` | Daemon initializer (one-time) | First daemon startup |
  | `arcs/arc-{n}/` | `/state-new arc` CLI | Arc creation |
  | `arcs/arc-{n}/stages/` | `/state-new arc` CLI | Arc creation (pre-creates stages dir) |
  | `arcs/arc-{n}/stages/stage-{n}/` | `/state-new stage` CLI | Stage creation |
  | `arcs/arc-{n}/stages/stage-{n}/slices/` | `/state-new stage` CLI | Stage creation (pre-creates slices dir) |
  | `arcs/arc-{n}/stages/stage-{n}/slices/slice-{n}/` | `/state-new slice` CLI | Slice creation |
  | `{worktree}/` under Slice | Worktree manager (v4) | Slice enters `worktree_ready` |
  | `state/` | Daemon initializer (one-time) | First daemon startup |

  **Lock-Free Append-Only Write Model:**
  - Artifact files are written atomically (write to temp file, then rename — POSIX atomic rename)
  - No file locks — the append-only model means: create new file or overwrite with atomic rename, never append-to-existing
  - Projector writes (status updates) use the same atomic rename pattern
  - Concurrent writes to the SAME artifact file: last writer wins (event store resolves conflicts — replay from event stream)
  - index.json rebuild: projector writes to `index.json.tmp`, atomically renames to `index.json` — readers always see a consistent state

  **Concurrent Worktree Rules:**
  - One worktree per Slice (D-04)
  - Worktree directory named by Slice ID: `worktree-slice-{n}/` or git branch name
  - Multiple worktrees CAN coexist — each in its own Slice directory
  - Worktree creation: worktree manager checks Slice status is `worktree_ready` before creating
  - Worktree cleanup: preserved on abandon (forensics per D-13), destroyed on Slice `shipped` (configurable retention via flag)

  **SECTION 4: Projector Rebuild Rules:**

  **Full Rebuild (daemon startup):**
  1. Projector truncates index.json
  2. Walks `.state/build/arcs/` directory tree
  3. For each artifact file found, reads frontmatter (or file stats for non-frontmatter files), creates IndexEntry
  4. Inserts entry into appropriate tier section keyed by aggregate ID
  5. Reconciles with event stream: removes entries for aggregates not found in event stream (orphan cleanup)
  6. Writes index.json atomically (write to index.json.tmp, rename)

  **Incremental Rebuild (per state.* event):**
  1. Projector receives event
  2. Extracts aggregate_id from event
  3. Reads affected artifact file(s) from disk
  4. Updates (or inserts) IndexEntry in the appropriate tier section
  5. Increments event_sequence
  6. Writes index.json atomically

  **Trigger Events → Index Updates:**
  | Event Pattern | Index Update |
  |---------------|-------------|
  | state.arc.* | Update arc entry + any child entries whose computed state changes |
  | state.stage.* | Update stage entry + recompute parent arc's child counts |
  | state.slice.* | Update slice entry + recompute parent stage's child counts |
  | state.step.* | Update step entry + recompute parent slice's step counts |

  4. If not found but valid format: return None (unresolved → W004 in Plan 03)
