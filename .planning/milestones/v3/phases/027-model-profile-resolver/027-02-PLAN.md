## Threat Model — Phase 027, Plan 02 (Implementation)

| Threat | Severity | Mitigation |
|--------|----------|-----------|
| Malformed/injected `step_profile` value in `handle_chat_params` body | high | `ModelProfile(step_profile_raw)` raises `ValueError` for unrecognized strings (enum coercion). The handler must catch `ValueError` and return a safe fallback (balanced profile) rather than propagating a 500. Do NOT let arbitrary strings reach `resolve_profile()`. |
| `overrides` dict injection — attacker sends `{"__class__": ..., "__init__": ...}` or other non-field keys | high | `ResolvedProfile.model_copy(update=overrides)` is called only from `resolve_profile()`. `ConfigDict(extra="forbid", frozen=True)` causes Pydantic to raise `ValidationError` for unknown field names. The handler stub (Phase 027) does NOT accept `overrides` from the HTTP body — overrides are only set programmatically by the daemon internals. Do NOT expose overrides via the HTTP interface in this phase. |
| `thinking_budget_tokens` integer overflow or negative value | medium | `ResolvedProfile.thinking_budget_tokens: int | None` has no explicit validator in Phase 027. The value comes from `_DEFAULTS` (hardcoded 4000) or programmatic overrides — not from HTTP input in this phase. Phase 029 applies additional Anthropic-SDK-level validation. Document in docstring that negative values are rejected by AnthropicClient (Phase 025/029). |
| Mode isolation violation — model_profile.py imports state_build.* or state_teach.* | high | `test_no_mode_silo_import` (test_model_profile.py) enforces this at test-run time. The implementation must contain zero imports from `state_build.*` or `state_teach.*`. CI import-graph lint also enforces this. Mitigation: keep model_profile.py in `state_core/providers/` (shared kernel), use only stdlib + pydantic + structlog. |
| `inherit` propagating to `_DEFAULTS` KeyError | medium | `resolve_profile()` explicit guard: `if resolved_name == ModelProfile.inherit: resolved_name = ModelProfile.balanced`. Hypothesis property test `test_resolve_never_returns_inherit` catches this for any input combination. |

    ```python
    async def handle_chat_params(body: dict[str, object]) -> dict[str, object]:
        """Handle POST /hook/chat-params from the opencode plugin shim.

        Phase 027 stub: reads step_profile from the request body;
        resolves against global defaults (no scope-stack lookup yet).
        Full scope-stack lookup (Arc/Phase/Slice/Step) is Phase 028 work.

        Args:
            body: Parsed JSON request body from the plugin shim.
                  Expected keys (all optional):
                    step_profile: str — one of "quality", "balanced", "budget", "inherit"

        Returns:
            Dict with camelCase keys matching the opencode chat.params hook output interface:
              temperature: float
              topP: float
              topK: int (always 0)
              maxOutputTokens: int | None
              options: dict (contains thinking_budget_tokens if quality profile)

        Security: invalid step_profile values are caught and treated as None (falls back to balanced).
        Overrides are NOT accepted from the HTTP body (Phase 027 scope).
        """
        step_profile_raw = body.get("step_profile")
        step_profile: ModelProfile | None = None
        if step_profile_raw is not None:
            try:
                step_profile = ModelProfile(step_profile_raw)
            except ValueError:
                log.warning(
                    "hooks.chat_params.invalid_profile",
                    step_profile_raw=step_profile_raw,
                    fallback="balanced",
                )
                step_profile = None

        resolved = resolve_profile(step_profile=step_profile)
        params = build_chat_params(resolved)

        log.debug(
            "hooks.chat_params.resolved",
            profile=resolved.profile.value,
            model=resolved.model,
        )
        return params
    ```

    DO NOT import state_build.* or state_teach.*. Imports are limited to: stdlib, structlog, state_core.providers.model_profile.
