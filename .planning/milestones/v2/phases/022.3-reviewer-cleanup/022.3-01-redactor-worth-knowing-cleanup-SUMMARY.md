## Decisions Made

- **Sentinel naming:** Chose `CYCLE_SENTINEL` (mirrors `REDACTED` pattern) over alternatives like `_CYCLE_MARK` or hard-coding the literal. Greppable, length-uniform (7 chars), public-surface symmetry with `REDACTED`.
- **Cycle-guard scope:** Only check `id()` for container types (`dict, list, tuple, set, frozenset`). Strings and ints cannot self-reference, so checking `id()` on them would waste cycles and pollute the visited set with throwaway IDs. (Reviewer prescription confirmed.)
- **WK-03 list/tuple split:** Reviewer's prescription kept the combined `(list, tuple)` `isinstance` check, but lists never need the `_make` cascade. Splitting into two `if` branches reads more clearly and avoids unreachable code in the tuple-only fallback paths.
- **WK-05 widening to `int | None`:** Reviewer suggested `int` default; the orchestrator brief widened to `int | None` to support the "skip setLevel" path. Documented in the docstring's Args section as an operator/test ergonomic.
- **WK-06 chain via `from exc`:** Preserves the original traceback so an operator can see WHICH ProcessorFormatter failed and WHY — critical for diagnosing daemon-startup failures.
