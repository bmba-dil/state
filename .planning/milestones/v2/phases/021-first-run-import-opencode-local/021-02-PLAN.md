<threat_model>
ASVS L1 — block on HIGH. Implementation plan reads attacker-controlled auth.json (foreign data from opencode) and writes to state's vault.

- **T-021-02-1 (HIGH):** Path traversal via OPENCODE_AUTH_CONTENT or STATE_OPENCODE_AUTH_PATH allows reading arbitrary files. Mitigation:
  (a) `OPENCODE_AUTH_CONTENT` is parsed as IN-MEMORY JSON — never used as a path (`json.loads(env)` not `Path(env).read_text()`).
  (b) `STATE_OPENCODE_AUTH_PATH` is read as Path but ONLY passed to `Path(p).expanduser().resolve()` then `.read_bytes()` — no shell expansion, no os.system, no subprocess. Resolves symlinks (defends against symlink-to-/etc/passwd) and executor checks `path.is_file()` before reading.
  (c) Importer never echoes the path's CONTENTS — only the path STRING (which the user controls anyway) appears in structlog `auth.import.unreadable` events.

- **T-021-02-2 (HIGH):** Pydantic validation errors leak credential bytes through their default `repr()` of input data. Mitigation:
  - `_OpencodeApiEntry.key`, `_OpencodeOauthEntry.access`, `_OpencodeOauthEntry.refresh` use `Field(repr=False)` — same discipline as state's `_CredentialBase` (BASE-04 / Phase 011).
  - On `ValidationError`, the importer catches the exception and emits a structured WARN log with `provider_id` + `error_type` ONLY — never `e.errors()` (which contains the offending values). Acceptance criterion greps logs for canary substrings and asserts ZERO matches.

- **T-021-02-3 (HIGH):** auth.imported event payload accidentally carries secret bytes. Mitigation: payload constructed via `AuthImportedData(provider_id=..., cred_kind=..., source="opencode")` — a frozen pydantic model with `extra="forbid"` and ONLY 3 fields. Plan 01 Task 1's acceptance criterion already grep-asserts no `access`/`refresh`/`key`/`expires` in the class body. This plan re-asserts it via IMPORT-24 round-trip test.

- **T-021-02-4 (MEDIUM):** TOCTOU between path resolution and file read — attacker swaps file between `is_file()` check and `read_bytes()`. Mitigation: ACCEPTED RISK (low impact — opencode's auth.json is in user's home; if attacker has write there, they own the user's session anyway). Mirrors Phase 012's stance on POSIX mode race (declared out-of-scope at line 25-27 of store.py docstring). Threat documented but not blocked.

- **T-021-02-5 (MEDIUM):** Importer reads opencode's auth.json without enforcing 0o600 mode — opencode may have looser permissions, but state should not REFUSE to read foreign data. Mitigation: per CONTEXT.md decision ("do NOT enforce 0o600 on opencode's file — it's foreign; just read it"). The 0o600 enforcement is reserved for state's OWN vault (Phase 012). Importer logs the observed mode at INFO level on every import for audit visibility.

- **T-021-02-6 (HIGH):** All-or-nothing failure mode broken by partial-write race — if `save_vault()` is interrupted mid-write, vault is corrupt. Mitigation: relies on Phase 012's `_atomic_write` (open-write-fsync-rename); Phase 021 importer makes a SINGLE `save_vault()` call after all validation succeeds — never two writes per import session. Acceptance criterion: simulate ValidationError mid-translate → assert state's auth.json byte-identical to pre-import baseline (`hashlib.sha256` compare).

- **T-021-02-7 (MEDIUM):** Provenance marker `extras["_source"] = "opencode-import"` accidentally consumed as a real field by downstream loader. Mitigation: per CONTEXT.md ("Loader/runtime MUST ignore underscore-prefixed extras keys"). Phase 018 loader already does this; documented contract preserved by THIS phase via comment on the marker assignment.

- **T-021-02-8 (LOW):** Concurrent daemon boot races writing the vault. Mitigation: ACCEPTED — the daemon is launchd/systemd-managed singleton (PROJECT.md). filelock guarding (Phase 013) is for refresh, not boot. If a future arc allows parallel daemons, this becomes a real bug.

Severity floor: 3 HIGHs all addressed by structural mitigations (no path-as-shell, repr=False on secret fields, frozen 3-field event payload, single-call save_vault). No HIGH residuals.
</threat_model>

      1. STATE_OPENCODE_AUTH_PATH env var (state-side test/CI override)
      2. OPENCODE_AUTH_CONTENT env var (opencode-native, parses as inline JSON)
      3. $XDG_DATA_HOME/opencode/auth.json
      4. ~/.local/share/opencode/auth.json (Linux) | ~/Library/Application Support/opencode/auth.json (macOS)
    """
    # Windows out-of-scope per CONTEXT.md §Windows
    if os.name != "posix":
        return ("windows_unsupported", None)

    # 1. State-side override
    state_override = os.environ.get("STATE_OPENCODE_AUTH_PATH")
    if state_override:
        p = Path(state_override).expanduser().resolve()
        if p.is_file():
            return ("path", p)
        return ("absent", None)

    # 2. opencode-native env override (auth/index.ts:59)
    env_inline = os.environ.get("OPENCODE_AUTH_CONTENT")
    if env_inline:
        return ("env_inline", env_inline.encode("utf-8"))

    # 3. XDG_DATA_HOME
    xdg = os.environ.get("XDG_DATA_HOME")
    if xdg:
        p = Path(xdg).expanduser() / "opencode" / "auth.json"
        if p.is_file():
            return ("path", p.resolve())

    if sys.platform == "darwin":

    else:  # Linux + other POSIX
        default = Path.home() / ".local" / "share" / "opencode" / "auth.json"
    if default.is_file():
        return ("path", default.resolve())

    return ("absent", None)


# ── Parsing ───────────────────────────────────────────────────────────────


def parse_opencode_auth(raw: bytes | str) -> dict[str, dict[str, Any]]:
    """Parse opencode's auth.json bytes into a {provider_id: entry_dict} map.

    Wraps orjson.loads; raises orjson.JSONDecodeError on malformed input
    (caller catches and emits auth.import.unreadable WARN).
    """
    if isinstance(raw, str):
        raw = raw.encode("utf-8")
    data = orjson.loads(raw)
    if not isinstance(data, dict):
        raise ValueError(f"opencode auth.json root must be a dict, got {type(data).__name__}")
    return data


# ── Translation ───────────────────────────────────────────────────────────


def _translate_entry(provider_id: str, entry: dict[str, Any]) -> Credential | None:
    """Translate one opencode entry into a state Credential, or None to skip.

    Returns:
      OAuthCredential   — for opencode type=="oauth"
      ApiKeyCredential  — for opencode type=="api" (and key != OAUTH_DUMMY_KEY)
      None              — for type=="wellknown" OR OAUTH_DUMMY_KEY (skip)

    Raises:
      _ImportAborted    — wraps any pydantic ValidationError or unknown type;
                          caller catches and rolls back the entire import
    """
    entry_type = entry.get("type")
    try:
        if entry_type == "wellknown":
            _OpencodeWellKnownEntry.model_validate(entry)
            log.info(
                "auth.import.wellknown_skipped",
                provider_id=provider_id,
                reason="wellknown_unsupported",
            )
            return None

        if entry_type == "api":
            api = _OpencodeApiEntry.model_validate(entry)
            if api.key == _OPENCODE_OAUTH_DUMMY_KEY:
                log.debug(
                    "auth.import.dummy_skipped",
                    provider_id=provider_id,
                )
                return None
            # Provenance marker MUST be the LAST write so opencode metadata
            # CANNOT clobber it (CONTEXT.md decision §Provenance marker —
            # `extras["_source"] = "opencode-import"` is contractual).
            # An opencode entry whose `metadata` contains a stray `_source`
            # key would otherwise overwrite the marker if we wrote provenance
            # first and then `extras.update(api.metadata)`.
            extras: dict[str, Any] = dict(api.metadata) if api.metadata else {}
            extras[_PROVENANCE_KEY] = _PROVENANCE_VALUE  # always wins
            return ApiKeyCredential(
                key=api.key,
                provider_id=provider_id,
                extras=extras,
            )

        if entry_type == "oauth":
            oauth = _OpencodeOauthEntry.model_validate(entry)
            # Build extras with renames first, then stamp provenance LAST so
            # nothing can overwrite the marker (mirrors api branch above).
            extras = {}
            if oauth.enterpriseUrl is not None:
                # Field RENAME: opencode camelCase → state snake_case in extras
                extras["enterprise_url"] = oauth.enterpriseUrl
            extras[_PROVENANCE_KEY] = _PROVENANCE_VALUE  # always wins
            return OAuthCredential(
                access=oauth.access,
                refresh=oauth.refresh,
                expires=oauth.expires,                  # epoch seconds verbatim (CONTEXT.md §expires unit)
                account_id=oauth.accountId,             # field RENAME: accountId → account_id
                provider_id=provider_id,
                extras=extras,
            )

        # Unknown / missing type → abort the entire import (all-or-nothing)
        raise ValueError(f"unknown opencode entry type: {entry_type!r}")

    except (ValidationError, ValueError) as e:
        # Log structured error WITHOUT e.errors() (would leak validation input)
        log.warning(
            "auth.import.entry_validation_failed",
            provider_id=provider_id,
            error_type=type(e).__name__,
        )
        raise _ImportAborted(provider_id) from e


# ── Orchestration ─────────────────────────────────────────────────────────


def _identity(cred: Credential) -> tuple[str, str]:
    """Compute (provider_id, prefix) identity per CONTEXT.md §Identity."""
    secret = cred.access if cred.type == "oauth" else cred.key
    return (cred.provider_id, secret[:_IDENTITY_PREFIX_LEN])


async def import_from_opencode(
    *,
    vault_path: Path | None = None,
    store: Any | None = None,        # SqliteEventStore (Any to avoid forward-ref)
    mirror: Any | None = None,       # SyncEventMirror
) -> int:
    """Run the first-run import. Returns count of credentials newly imported.

    Idempotent: subsequent runs append-only — same (provider_id, prefix)
    is detected as already present and skipped.

    See module docstring for the cardinal rules. See CONTEXT.md for the
    locked decisions backing every branch here.
    """
    kind, payload = discover_opencode_auth_path()

    if kind == "absent":
        log.debug(
            "auth.import.absent",
            paths_probed=[
                "STATE_OPENCODE_AUTH_PATH (env)",
                "OPENCODE_AUTH_CONTENT (env)",
                "$XDG_DATA_HOME/opencode/auth.json",
                "~/.local/share/opencode/auth.json | ~/Library/Application Support/opencode/auth.json",
            ],
        )
        return 0

    if kind == "windows_unsupported":
        log.warning(
            "auth.import.windows_unsupported",
            hint="opencode importer is POSIX-only (mirrors Phase 012)",
        )
        return 0

    # Load opencode bytes
    if kind == "env_inline":
        assert isinstance(payload, bytes)
        raw_bytes = payload
        source_label = "env_inline"
    else:  # kind == "path"
        assert isinstance(payload, Path)
        try:
            raw_bytes = payload.read_bytes()
            source_label = str(payload)
        except (FileNotFoundError, PermissionError, OSError) as e:
            log.warning(
                "auth.import.unreadable",
                path=str(payload),
                reason=type(e).__name__,
            )
            return 0

    log.info("auth.import.found", kind=kind, source=source_label)

    try:
        opencode_data = parse_opencode_auth(raw_bytes)
    except (orjson.JSONDecodeError, ValueError) as e:
        log.warning(
            "auth.import.unreadable",
            path=source_label,
            reason=type(e).__name__,
        )
        return 0

    log.info("auth.import.started", entry_count=len(opencode_data))

    # Translate ALL entries first (all-or-nothing). Any failure aborts.
    #
    # NOTE on input-side dedup: opencode's auth.json is structurally
    # `Record<provider_id, Info>` (a single JSON object keyed by
    # provider_id), so duplicate provider_ids are IMPOSSIBLE at the JSON-
    # object layer — orjson.loads collapses repeated keys to the last
    # value before we ever see the dict. Therefore an in-loop
    # `seen_identities` set would be unreachable for any normal opencode
    # shape and we omit it. Cross-state-vault dedup (the case the
    # CONTEXT.md cares about) happens in the diff step further down,
    # against `existing_vault.providers[pid]`.
    candidates: list[Credential] = []
    try:
        for provider_id, entry in opencode_data.items():
            cred = _translate_entry(provider_id, entry)
            if cred is None:
                continue
            candidates.append(cred)
    except _ImportAborted:
        # Already logged in _translate_entry; vault untouched.
        return 0

    # Untracked-provider INFO logs (validate after translation, before save)
    for cred in candidates:
        if cred.provider_id not in _KNOWN_PROVIDER_IDS:
            log.info(
                "auth.import.untracked_provider_imported",
                provider_id=cred.provider_id,
            )

    # Load existing state vault and diff
    target_path = vault_path if vault_path is not None else get_auth_json_path()
    existing_vault = load_vault(target_path)

    new_creds: list[Credential] = []
    candidate_vault = AuthVault(
        schema_version=existing_vault.schema_version,
        providers={
            pid: list(creds) for pid, creds in existing_vault.providers.items()
        },
        last_rotation=dict(existing_vault.last_rotation),
    )

    for cand in candidates:
        existing = candidate_vault.providers.get(cand.provider_id, [])
        existing_idents = {_identity(c) for c in existing}
        if _identity(cand) in existing_idents:
            # Already present — skip (state-side cred wins, never mutated)
            continue
        # Append at END (preserves rotation index for state-native creds)
        candidate_vault.providers.setdefault(cand.provider_id, []).append(cand)
        new_creds.append(cand)

    if not new_creds:
        log.info("auth.import.completed", count=0)
        return 0

    # Single transactional write
    save_vault(target_path, candidate_vault)

    # Emit one auth.imported event per newly-imported cred (dual-write)
    if store is not None:
        for cred in new_creds:
            data = AuthImportedData(
                provider_id=cred.provider_id,
                cred_kind=cred.type,
            )
            await store.append(
                aggregate_type="auth",
                aggregate_id=f"opencode-import:{cred.provider_id}",
                event_type="state.auth.imported",
                data=data.model_dump(),
                mirror=mirror,
            )
            log.info(
                "auth.import.credential_imported",
                provider_id=cred.provider_id,
                cred_kind=cred.type,
            )

    log.info("auth.import.completed", count=len(new_creds))
    return len(new_creds)
