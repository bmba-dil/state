    ### Step 4: Hypothesis ≥1000-draw verification (REDACT-24)

    RESEARCH §Sampling Rate pins the phase gate to ≥1000 hypothesis draws on REDACT-24. Plan 01's RED stub uses `max_examples=200` to keep the per-task feedback loop under 5s; this gate step OVERRIDES that with a phase-gate-only run at `max_examples=1000, deadline=None`. The override is a transient pytest-side augmentation — Plan 01's source file is NOT edited.

    The override is implemented via a one-shot pytest harness file written to a tempdir. The harness re-imports the property test's strategy and decorates a fresh test function with `@settings(max_examples=1000, deadline=None)` so the RESEARCH §Validation Architecture verbatim template runs at the phase-gate sample rate. This avoids editing Plan 01's RED-stub source (which the verifier expects to remain at `max_examples=200` for fast per-task sampling).

    ```bash
    GATE_HARNESS="$(mktemp -d)/test_phase020_gate_hypothesis.py"
    cat > "$GATE_HARNESS" <<'PY'
    """Phase 020 phase-gate-only hypothesis run at max_examples=1000.

    Re-runs REDACT-24 with the RESEARCH §Sampling Rate pinned 1000-draw target.
    Plan 01's RED stub uses max_examples=200 for per-task feedback latency;
    this harness exists ONLY for the Plan 04 verification gate.
    """
    from hypothesis import given, settings, strategies as st
    from state_core.observability.redactor import _redact_string, REDACTED


    @settings(max_examples=1000, deadline=None)
    @given(
        prefix=st.sampled_from([
            "sk-ant-oat-", "sk-ant-api03-", "sk-or-v1-",
            "ya29.", "1//", "gho_", "ghu_", "ghs_", "ghp_",
            "gsk_", "xai-", "esecret_",
        ]),
        body=st.text(
            alphabet=st.characters(
                whitelist_categories=("Ll", "Lu", "Nd"),
                whitelist_characters="_-",
            ),
            min_size=20, max_size=200,
        ),
        surround=st.text(min_size=0, max_size=20),
    )
    def test_phase_gate_hypothesis_1000_draws(prefix, body, surround):
        secret = prefix + body
        blob = f"{surround}{secret}{surround}"
        out = _redact_string(blob)
        assert secret not in out, f"redactor missed: {secret!r} survived as {out!r}"
        assert REDACTED in out, f"no [REDACTED] marker in {out!r}"
    PY

    pytest "$GATE_HARNESS" \
        --hypothesis-show-statistics \
        --hypothesis-seed=0 \
        -p no:cacheprovider \
        -v 2>&1 | tee /tmp/phase020-hypothesis.log | tail -40

    # Confirm ≥1000 examples generated (line format from hypothesis ≥6.120 stats output).
    EXAMPLES=$(grep -oE "[0-9]+ passing examples" /tmp/phase020-hypothesis.log | head -1 | grep -oE "[0-9]+")
    if [ -z "$EXAMPLES" ] || [ "$EXAMPLES" -lt 1000 ]; then
      echo "FAIL: hypothesis statistics did not show ≥1000 examples (got: ${EXAMPLES:-NONE})"
      cat /tmp/phase020-hypothesis.log | tail -50
      exit 1
    fi
    echo "Phase gate hypothesis run: $EXAMPLES examples (target ≥1000)"

    # Also re-run the in-tree REDACT-24 test (max_examples=200) to confirm Plan 01's stub still passes:
    pytest tests/test_redactor.py::test_hypothesis_secrets_never_survive \
        --hypothesis-show-statistics -v 2>&1 | tail -10
    ```

    Required outcome:
    - Exit code 0 for the gate harness run
