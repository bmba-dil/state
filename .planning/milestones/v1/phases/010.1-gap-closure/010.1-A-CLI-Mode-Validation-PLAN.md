### Task 1: Add _validate_mode callback

<read_first>src/state_cli/main.py</read_first>

<action>
Add a Typer callback function at the top of the events sub-app module:

```python
import typing
from src.state_core.schema import Mode

VALID_MODES: typing.Final[set[str]] = {"build", "teach", "kernel"}

def _validate_mode(value: str | None) -> str | None:
    if value is not None and value not in VALID_MODES:
        raise typer.BadParameter(f"Invalid mode '{value}'. Must be one of: {', '.join(sorted(VALID_MODES))}")
    return value
```

Update each command's `--mode` option to use the callback:
```python
mode: str | None = typer.Option(None, "--mode", callback=_validate_mode, help="Filter by mode (build, teach, kernel)")
```

Apply to all three: `tail()`, `replay()`, `export()`.
</action>
