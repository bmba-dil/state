       Returns a `Box({ flexDirection: "column" })` with the following sections:

       **A. Concept header** (2 rows):
       - Row 1: `● Concept: {name}` — status dot (● U+25CF) in accent color, "Concept:" prefix in accent + bold, concept name in accent + bold. Truncated at 28 chars. If `concept` is null, shows `● No active concept` (textMuted, dim).
       - Row 2: `◈ {stage_label}` — stage indicator (◈ U+25C8) in info color, Kolb stage display name (from `kolbStageLabel()`) in info color, dim attribute. Rendered only when concept is non-null. 2-space indent from left edge.
       - Stage colors per Kolb stage (all use `T.info` for simplicity — consistent, readable, and the info token semantically maps to informational/learning content):
         - All 4 stages use `T.info` (#3B82F6) for the stage indicator and label.

       **B. Divider** (1 cell tall):
       - 28 `─` characters (U+2500) with `fg: T.border`. Always rendered regardless of concept nullity — separates header from content area.
       - Rendered as: `Txt({ fg: T.border, height: 1 }, "\u2500".repeat(28))`

       **C. Description** (2-3 lines, concept non-null only):
       - Split concept description into lines that each fit within 28 chars (split at word boundaries where possible, truncating each line with U+2026 if needed)

       - Rendered only when `concept` is non-null and `connection === "connected"`
       - If `concept` is null and connection === "connected", show empty state:

       - Second divider (28 `─` chars, border color) above the mastery bar

         - Note: the masterBar string contains mixed colors (accent for ▓, textMuted for ░) but is rendered as a single Text element. The fg prop sets the accent fill color; the empty blocks ░ are visually distinct because they're the U+2591 light-shade character which appears dimmer regardless of fg. This is a terminal rendering constraint — the bar's visual distinction comes from character choice, not per-character color.
         - Rendered only when `concept` is non-null and `connection === "connected"`

       **E. Connection error states** (when connection !== "connected"):

Run state-daemon start to resume." is 66 chars but "Run state-daemon start to resume." fits at 34 chars (truncated to 28 with U+2026: "Run state-daemon start to…"), so the recovery instruction is split as "Run state-daemon start to" / "resume."

       ```typescript

       ```
       Returns a 28-cell-wide string: fill blocks (▓) + empty blocks (░) + percentage label.
       
       **Bar width:** 20 cells (leaving 8 cells for the percentage label: 1 space + up to 4 chars for "100%").

       - Clamped to [0, 20]
