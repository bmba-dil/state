```typescript
export interface PromptHintState {
  connection: ConnectionStatus;
  model: string | undefined;  // full model ID from event (e.g. "deepseek/deepseek-v4-pro")
  cost: number;                // USD amount from step.ended (e.g. 0.42)
  stepCount: number;           // incremented on each step.ended
}
```

**Import formatCost from statusline.ts — do NOT re-implement:**
```typescript
import { formatCost } from "./statusline.js";
```
formatCost is the canonical cost formatter — it validates finite numbers, clamps to 0–100000, and returns `"$X.XX"` or `"—"`. This plan does NOT re-implement cost formatting.

**shortenModelID(id: string): string:**
- Truncates a full model ID to the last segment after the final `/` for display compactness.
- `"deepseek/deepseek-v4-pro"` → `"deepseek-v4-pro"`
- `"anthropic/claude-sonnet-4-20250514"` → `"claude-sonnet-4-20250514"`
- `"openai/gpt-4o"` → `"gpt-4o"`
- If no `/` in the string, return as-is (defensive fallback).
- If id is empty or undefined → return `"—"` (em dash).
- This is a pure function with no side effects — trivially testable.

**renderPromptHint() implementation:**
- Reads cost, model, stepCount, connection from `PROMPT_HINT_STATE` synchronously.
- Returns a single `Box({ flexDirection: "row", height: 1 })` containing Text elements separated by middot (U+00B7) spaces.
- Line format: `{model} · {cost} · Step {N}`
  - model = `shortenModelID(STATE.model)` if model is defined, otherwise `"—"`
  - cost = `formatCost(STATE.cost)`
  - step = `Step ${STATE.stepCount}` when connection is "connected", `"—"` otherwise
- Maximum width: **28 cells** (truncate with U+2026 ellipsis if longer — use the `truncate()` utility).
- Model text colored with theme `accent` (#6366F1) using ATTR_BOLD.
- Cost and step text colored with theme `textMuted` (#64748B).
- If connection is "unreachable": show only a dimmed `"—"` in textMuted color (no model/cost/step data).
- If connection is "disconnected": show last-known data with ATTR_DIM applied.
- If stepCount is 0 (no steps completed yet): show `"—"` for step portion.

**setupPromptHint(api):**
- Subscribe to `api.event.on("session.next.model.switched", handler)`:
  - Store `event.properties.id` (full model ID) in `PROMPT_HINT_STATE.model`.
  - Set `PROMPT_HINT_STATE.connection = "connected"`.
- Subscribe to `api.event.on("session.next.step.ended", handler)`:
  - Store `event.properties.cost` in `PROMPT_HINT_STATE.cost` (defensively: only if `typeof cost === "number" && isFinite(cost)`).
  - Increment `PROMPT_HINT_STATE.stepCount` by 1.
  - Set `PROMPT_HINT_STATE.connection = "connected"`.
- Subscribe to `api.event.on("session.status", handler)`:
  - Set `PROMPT_HINT_STATE.connection = "connected"`.
- Register all unsub functions via `api.lifecycle.onDispose`.
- On dispose: reset STATE to factory defaults (`model: undefined, cost: 0, stepCount: 0, connection: "unreachable"`).
- Log setup event via `log()` consistent with other TUI modules (event key: `"prompt-hint.setup"`, list subscriptions).

| T-087-01 | Tampering | `prompt-hint.ts` — step.ended cost handler | mitigate | Validate `event.properties.cost` with `typeof cost === "number" && isFinite(cost)` before storing. Invalid/falsy cost values are silently ignored (state retains last valid cost). match statusline.ts T-084-01 pattern. |
