<objective>
Create a one-line statusline component for `sidebar_footer` and `home_footer` TUI slots showing: mode icon · scope · provider name · session cost. Subscribes to daemon SSE cost and status events via `api.event` bus, updates module-level state on each event, and renders synchronously on every frame using @opentui/core constructs API (Box, Text).

Purpose: Give the user at-a-glance session context — which mode they're in, what step is active, which provider is handling the request, and how much the session has cost so far — rendered as a compact single-line footer.

Output: One new source file (`statusline.ts`), one test file (`statusline.test.ts`), one modified file (`tui.ts` with slot wiring replaced from placeholder to renderStatusline).
</objective>
