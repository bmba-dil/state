<objective>
Complete the plugin-side hot-reload chain: when the opencode plugin's event hook receives
`state.mode.activated` (emitted by the daemon via Plan 01), re-read `mode.json` and compute
the correct MCP server list. Extract a shared `getMcpServersForMode()` pure function so both
the `config` hook (boot-time) and `event` hook (hot-reload) share the same mode→server mapping.

Purpose: Ensure the event hook fully completes its half of the hot-reload contract — it not
only re-reads mode state but also computes and logs the expected MCP server list. The actual
dynamic re-registration of MCP servers at runtime requires the daemon client API (Phase 061);
this plan ensures the plugin side is fully prepared.

Output: Extracted `getMcpServersForMode()` in config.ts, updated event.ts with server
computation and structured logging, refactored `applyMcpRegistration()` to delegate.
</objective>
